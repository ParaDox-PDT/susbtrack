# SubTrack detail screen assets

Figma board: https://www.figma.com/design/5QsiZgkUNJgIjEXt6nezd0/SubTrack?node-id=18-565

Four mobile frames (356 × 920): Gmail scanning, Review found subscriptions, Edit Spotify subscription, Notifications settings. Text, form rows, controls, and cards are editable; two illustrations are static image layers.

Created with the built-in image generation tool using `assets/screen_images/detail.png` as the reference. Original PNG assets are preserved; JPEG copies at quality 85 are embedded in the Figma import to reduce transfer size.
